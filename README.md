# WorkDesk 一体工作台

双击桌面「WorkDesk 一体工作台」，或直接运行 `launcher\WorkDeskLauncher.exe`。本机地址：http://127.0.0.1:5190/ 。使用原生启动器，不需要修改 PowerShell 执行策略。

## 使用

1. 左侧切换调研、提示词调优、智能体协作；模块按需启动，切换时保留页面。
2. 打开模块中的结果，点击顶部「收集当前结果」存入共享材料。
3. 编辑共享材料，发送到调研问题、提示词草稿或新协作目标，检查后自行开始处理。
4. 设备页面可检查 GuIO、列出设备并打开原生操作面板。需要执行操作时在 GuIO 中完成。

提示词只传递已采纳候选；没有采纳时传递原版。调研问题最多 1000 字，长报告可先精简，或直接送入智能体协作目标。共享材料可导入、导出 JSON，保存新版本时保留历史。

## 安装与数据

- 当前整合采用统一工作台、固定本机模块接口和材料交接；三个网页模块仍使用已有服务及业务逻辑。GuIO 保留独立桌面窗口。
- 原模块的记录、加密设置与数据目录沿用，未迁移或删除。浏览器中的草稿因新入口地址不同，有独立的本地存储；旧入口浏览器草稿仍在原地址。
- WorkDesk 共享材料：`%LOCALAPPDATA%\WorkDesk\materials`；运行日志：`%LOCALAPPDATA%\WorkDesk\logs`。
- 本工作台仅监听回环地址；调研模块原有的外部搜索和本机 Ollama 行为沿用。
- 关闭工作台窗口不会中断模块中的任务。再次启动会复用仍在运行的服务。
- 工作台源码：`E:\xiangmujihua\WorkDesk`；启动器源码：`E:\xiangmujihua\WorkDeskLauncher`；安装：`E:\xiangmujihua\apps\WorkDesk`。
